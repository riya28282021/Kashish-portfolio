# Kashish Mittal — Personal Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `kashish-mittal-portfolio` folder.
3. Double-click `index.html` to preview in a browser.

For a local development server, open the folder in VS Code and run:
`python3 -m http.server 8000`
Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a GitHub repository (for example `kashish-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. In repository Settings → Pages, choose Deploy from a branch → `main` → `/ (root)`.
4. Save and wait for the Pages URL.

## Personalise before publishing
- In `index.html`, replace `YOUR_EMAIL@example.com` with the correct enquiry email.
- Replace the placeholder LinkedIn and GitHub links.
- Add a CV PDF and update the Download CV link to its filename.
- Add verified audience reach, campaign and event statistics.
- Review the brand list and role descriptions for exact attribution and dates.
- Add video/showreel links and case studies when ready.

The contact button opens the visitor's email app (mailto). No backend or data collection is used.
